Comparing polynomial, GLM, nonlinear, and Tier-3 engines

Model comparison in rsmFlow is deliberately multi-criterion. AIC, BIC, RMSE, convergence, diagnostics, scientific plausibility, prediction, and optimum stability answer different questions. Quasi-likelihood fits are not assigned likelihood AIC/BIC rankings by rsm_compare_engines().

Example 1: Gaussian LM versus Gaussian GLM

set.seed(401)
d <- expand.grid(x1=seq(-1,1,length.out=8),x2=seq(-1,1,length.out=8))
d$y <- 8 + .4*d$x1-.3*d$x2-.7*d$x1^2-.4*d$x2^2+rnorm(nrow(d),0,.08)
lm_fit <- rsm_fit(d,"y",c("x1","x2"))
glm_fit <- rsm_glm_fit(d,"y",c("x1","x2"),family=gaussian())
rsm_compare_engines(LM=lm_fit,GLM=glm_fit)
#>   name         kind     engine       RMSE        MAE   logLik       AIC
#> 1   LM gaussian_rsm        ols 0.07938592 0.06567613 71.32772 -128.6554
#> 2  GLM          glm stats::glm 0.07938592 0.06567613 71.32772 -128.6554
#>         BIC converged
#> 1 -113.5433      TRUE
#> 2 -113.5433      TRUE

Example 2: polynomial approximation versus nonlinear saturation

n <- expand.grid(N=seq(10,160,length.out=8),P=seq(5,90,length.out=7))
n$y <- 11*n$N/(30+n$N)*n$P/(20+n$P)+rnorm(nrow(n),0,.08)
poly <- rsm_fit(n,"y",c("N","P"))
nonlin <- rsm_nonlinear_fit(n,"y",c("N","P"),"michaelis_menten2",
  start=c(A=11,K1=30,K2=20),engine="nls")
rsm_compare_engines(Polynomial=poly,Nonlinear=nonlin)
#>         name         kind engine       RMSE        MAE    logLik        AIC
#> 1 Polynomial gaussian_rsm    ols 0.39885393 0.32353296 -27.98760   69.97519
#> 2  Nonlinear    nonlinear    nls 0.07308131 0.05542551  67.04567 -126.09134
#>          BIC converged
#> 1   84.15266      TRUE
#> 2 -117.98993      TRUE

Example 3: compare operational optima

op1 <- rsm_optimize(poly,"max","L-BFGS-B")
op2 <- rsm_optimize(nonlin,"max","L-BFGS-B")
rsm_compare_optima(Polynomial=op1,Nonlinear=op2)
#>         name        N       P predicted   method
#> 1 Polynomial 155.2975 88.8362  7.614845 L-BFGS-B
#> 2  Nonlinear 160.0000 90.0000  7.564557 L-BFGS-B

A close optimum can coexist with different parameter interpretations; conversely, similar RMSE can hide materially different optima. For decision-oriented RSM, model adequacy should therefore be evaluated not only at the coefficient level but also in the location, uncertainty, and practical flatness of the optimum.
