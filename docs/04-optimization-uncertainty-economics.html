rsmFlow: Optimization, Optimum Uncertainty, and Economics

Optimization, optimum uncertainty, and economics

Role in the vignette curriculum. This deep dive owns constrained optimization, target search, optimizer comparison, uncertainty in optimum coordinates, joint regions, near-optimal operating zones, uncertainty-aware optimization, optimum stability, and biological-versus-economic decisions. Multiresponse trade-offs are developed in the next vignette.

1. An optimum is an estimated decision, not a fact

A response-surface optimum depends on:

  • model specification;
  • estimated parameters;
  • factor bounds;
  • optimization objective;
  • optimizer behavior;
  • uncertainty in the fitted surface.

Therefore, a defensible analysis reports more than one coordinate vector.

For optimum inference, uncertainty in the factor settings themselves is central (Wan et al. 2016).

3. Stationary geometry versus bounded decision

can <- rsm_canonical(fit)
can
#> Canonical analysis
#> Nature: maximum 
#> Stationary point:
#>           N           K  Irrigation 
#> 137.2206244  95.9724829   0.8134653 
#> Predicted response: 9.243603 
#> Inside region: TRUE

The stationary point solves the unconstrained quadratic geometry. The operational decision is restricted to feasible bounds.

opt <- rsm_optimize(
  fit,
  goal="max",
  method="hybrid",
  seed=601
)
opt
#> rsmFlow optimum
#> Goal: max  | method: L-BFGS-B 
#>           N           K  Irrigation 
#> 137.2206244  95.9724828   0.8134653 
#> Predicted response: 9.243603

Interpretation

If the bounded optimum lies on a factor limit, report that explicitly. A boundary optimum means the experiment supports a best point within the tested region, not necessarily a global biological maximum.

4. Explicit bounds

b <- list(
  lower = c(N = min(dat$N), K = min(dat$K), Irrigation = min(dat$Irrigation)),
  upper = c(N = max(dat$N), K = max(dat$K), Irrigation = max(dat$Irrigation))
)

opt_b <- rsm_optimize(
  fit,
  goal="max",
  method="L-BFGS-B",
  bounds=b
)

Use tighter bounds when engineering, agronomic, regulatory, or safety constraints restrict the feasible operating region.

5. Grid search

opt_grid <- rsm_optimize(
  fit,
  goal="max",
  method="grid",
  grid_n=41

Grid search is transparent and useful for teaching and verification, but resolution grows rapidly with dimensionality.

6. L-BFGS-B

opt_lbfgs <- rsm_optimize(
  fit,
  goal="max",
  method="L-BFGS-B"
)

Efficient for smooth bounded surfaces.

7. Genetic algorithm

opt_ga <- rsm_optimize(
  fit,
  goal="max",
  method="GA",
  seed=602,
  ga_control=list(popSize=100,maxiter=400,run=80)
)

Use a stochastic global search when multimodality or difficult constraints make local search less reliable. Freeze the seed for reproducibility.

Target optimization is useful for pH, firmness, concentration, moisture, and quality specifications.

12. Why optimum coordinates are uncertain

If fitted coefficients are random, the optimum is a derived random quantity:

\[ \hat{\mathbf{x}}_{opt}=h(\hat{\boldsymbol\beta}). \]

A coefficient table does not directly quantify uncertainty in \(h(\cdot)\).

20. Economic optimization

Biological maximum:

\[ \max_{\mathbf x}\hat y(\mathbf x). \]

Economic objective:

\[ \max_{\mathbf x}\left[ P_y\hat y(\mathbf x) -\sum_i c_i(x_i-x_{i,0}) -C_0 \right]. \]

Here \(x_{i,0}\) is a baseline at which incremental factor cost begins.

24. Boundary optima need explicit language

If any optimal coordinate equals its lower or upper bound, write:

“The best fitted setting within the experimental region occurred on the upper N boundary.”

Do not write:

“The true optimum N rate is the upper tested dose.”

The first is supported by the experiment. The second extrapolates beyond the evidence.

25. Uncertainty method depends on model family

For Gaussian polynomial models, coefficient simulation and bootstrap-style workflows are natural.

For likelihood GLMs, parametric simulate/refit/re-optimize is preferred where implemented.

For quasi families, asymptotic coefficient simulation is more appropriate than pretending a full likelihood exists.

For nonlinear models, refit bootstrap is preferable when the error model supports it; generalized nonlinear variance/correlation structures need additional care.

Always inspect the method stored in the uncertainty object.

26. Three decision scenarios

Scenario A: sharp interior maximum

Expect a compact optimum cloud and relatively small near-optimal zone.

Scenario B: broad plateau

Expect large coordinate uncertainty but potentially stable predicted response. Report an operating zone rather than one coordinate.

Scenario C: boundary optimum

Expect truncation. Consider a new experiment beyond the current boundary only if scientifically feasible and safe.

28. Common mistakes

  1. Reporting the unconstrained stationary point as a feasible recommendation.
  2. Ignoring boundary status.
  3. Giving optimum coordinates without uncertainty.
  4. Hiding failed bootstrap/refit replicates.
  5. Treating a covariance ellipse approximation as an exact confidence region.
  6. Reporting a single point when a broad near-optimal zone exists.
  7. Optimizing a model that failed diagnostics.
  8. Using economic costs on coded units without defining a natural-unit baseline.
  9. Treating one price scenario as permanent truth.
